# Gemini

[English](README.md) | 简体中文

**Rei Yuki 的非官方 AI 拟人角色设定集**


这是一套为 **Gemini** 设计的非官方个人拟人形象。角色视觉以蓝白配色为主，特征包括蓝紫色长双马尾、蓝瞳、猫耳耳机，以及身上的蝴蝶结与星形挂饰。

本项目纯属个人创作，与 Google 没有任何隶属、合作、赞助或官方认可关系。
