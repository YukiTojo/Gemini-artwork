# Gemini

English | [简体中文](README.zh-CN.md)

**Unofficial AI Personification Character Art Set by Rei Yuki**


This repository contains my unofficial character design for **Gemini**. Her visual design features a blue-and-white color scheme, long blue-purple twintails, blue eyes, cat-ear headphones, and bow and star accessories.

This is a personal creative project and is not affiliated with, endorsed, sponsored, or approved by Google.
